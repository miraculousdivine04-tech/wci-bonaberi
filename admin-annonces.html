1. Connexion à GitHub

Le jeton n'est jamais enregistré : il reste dans la page et n'est envoyé qu'à GitHub (api.github.com).

Pourquoi un jeton et pas mon mot de passe ?

Depuis 2021, GitHub refuse le mot de passe normal pour envoyer du code (push). Il faut un « jeton d'accès personnel », qui s'utilise exactement comme un mot de passe et que tu peux supprimer à tout moment.

  1. Connecte-toi à GitHub, puis ouvre github.com/settings/personal-access-tokens/new.
  2. Donne-lui un nom (ex : « admin annonces »), une durée (ex : 90 jours).
  3. Repository access → Only select repositories → choisis le dépôt du site.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Clique sur Generate token, copie-le et colle-le ci-dessus.
